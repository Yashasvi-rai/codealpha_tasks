# 📂 Projects

## 1️⃣ NovaCalc — Modern Calculator

### 🧮 Project Overview

**NovaCalc** is a modern, responsive calculator application designed with a clean glassmorphism-inspired interface.

The application provides basic arithmetic operations along with additional interactive features such as calculation history, keyboard support, and theme switching.

The calculator interface includes numeric buttons, arithmetic operators, percentage, decimal input, delete, clear, and result functionality.

### ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage
* 🔢 Decimal calculations
* 🧹 Clear / All Clear
* ⌫ Delete last character
* ⌨️ Keyboard support
* 🧾 Calculation history
* 🌙 Dark/Light theme
* 🎨 Animated gradient background
* 💎 Glassmorphism UI
* 📱 Responsive design
* ⚡ Instant calculation

The JavaScript implementation handles expression evaluation, calculation history, keyboard input, deletion, clearing, and theme switching.

### 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts — Poppins**
* **Font Awesome**

The styling includes animated gradients, floating elements, glassmorphism cards, responsive layouts, and separate light-mode styling.

### 📁 Project Structure

```text
NovaCalc/
│
├── index.html
├── style.css
└── script.js
```

### ▶️ How to Run

1. Download or clone this repository.
2. Navigate to the NovaCalc project folder.
3. Open `index.html` in a modern web browser.
4. Start performing calculations.

No backend or installation is required.

# 2️⃣ Galaxy Gallery — Interactive Image Gallery

### 🌌 Project Overview

**Galaxy Gallery** is a visually immersive and interactive image gallery built using HTML, CSS, and JavaScript.

The project focuses on creating a premium gallery experience using animations, glassmorphism, responsive layouts, image interactions, filtering, searching, favorites, and an interactive lightbox.

The interface includes categories such as Nature, Cities, Animals, Food, Cars, Travel, and Space.

### ✨ Features

#### 🖼️ Gallery

* Responsive image grid
* Multiple image categories
* Image cards with hover effects
* Image titles and ratings
* Featured/trending badges
* Interactive image overlays

#### 🔍 Search & Filters

* Live image search
* Category-based filtering
* All images filter
* Nature
* Cities
* Animals
* Food
* Cars
* Travel
* Space

The search functionality dynamically displays matching gallery cards, while category buttons filter cards according to their assigned classes.

#### ❤️ Favorites

Users can mark images as favorites, with favorite selections stored using **localStorage**, allowing the state to persist in the browser.

#### 🔎 Lightbox

* Full-size image preview
* Next image
* Previous image
* Close functionality
* Keyboard navigation
* Touch/swipe navigation
* Image download

The lightbox supports `Escape`, `ArrowRight`, and `ArrowLeft` keyboard controls.

#### 🎲 Gallery Controls

* 🔀 Shuffle gallery
* ✨ Random image
* ❤️ Like button
* 📥 Download image
* 🔝 Scroll-to-top
* 🎵 Music player
* 🌙 Theme switching
* 🎉 Confetti effect

#### ✨ Animations & Effects

* Animated gradient background
* Floating blobs
* Particle animation
* Cursor glow
* 3D card tilt
* Image zoom
* Scroll reveal
* Hover effects
* Staggered animations
* Loading animations

The JavaScript implements cursor glow and 3D card tilt interactions, while the CSS provides animated backgrounds, floating blobs, particles, and gallery-card effects.

### 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts — Poppins**
* **Font Awesome**
* **Unsplash Images**
* **Browser Local Storage**

### 📁 Project Structure

```text
Galaxy-Gallery/
│
├── index.html
├── style.css
├── script.js
└── music.mp3
```

### ▶️ How to Run

1. Clone or download this repository.
2. Navigate to the Galaxy Gallery folder.
3. Ensure all project files are present.
4. Open `index.html` in a modern browser.
5. Explore the gallery and interact with the available features.

> **Note:** The gallery uses online image resources, so an internet connection may be required for the external images and fonts to load correctly.
